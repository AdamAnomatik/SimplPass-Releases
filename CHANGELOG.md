# Changelog

## 1.0.1 — 2026-10-14

- Fixed: SimplPass and its password prompt closed right after starting in 1.0.0. Install 1.0.1 over 1.0.0; protected folders and settings are kept.

## 1.0.0 — 2026-10-13

First public release.

- Password protection for regular folders in place: names stay visible, contents are encrypted.
- Password prompt that names the app, file and folder, with a Caps Lock warning.
- **Protect with SimplPass** in the File Explorer folder menu.
- Protected, Open and Operation interrupted states with safe recovery.
- Native Windows 11 look with light and dark themes; Russian and English interface.
